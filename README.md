# The Barths Before 1900

A one-page family history of nine generations of a Barth line before 1900, from Detligen near Bern through Quatzenheim in Alsace to Iowa and Minnesota. It shows where each man lived, his church, the language and how the records describe where he belonged.

Read it at https://mhuot.github.io/barth-family/
